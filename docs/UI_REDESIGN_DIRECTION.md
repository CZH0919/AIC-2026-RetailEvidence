研究日期：2026-10-19。阶段：**官方公开资料已查阅；本轮实际截图已审阅，功能基线已完成，三类样板已实施并完成受影响回归，方向尚未获用户确认。** 本文件记录推荐，不能当作三页样板的验收或用户审美批准。

## 2. 当前可确认事实与尚待截图的问题

基线 main 的源码核查见 UI_REDESIGN_BASELINE：既有白色表面、青绿品牌、分隔线及表格均已有价值，应保留。没有证据支持“全站有大量机器人/星光/发光大屏”的泛化判断。

| 静态观察 | 可能影响 | 处理提案 | 当前页面证据 |
|---|---|---|---|
| 项目库34px标题、项目26px标题、页头间距多组值 | 层级及密度不稳定 | 样板采用统一22/18/14层级，最终按200%缩放核实 | before_v2/1440_report.png；768_report.png |

| 分类规则控件顺序堆叠，主要为内联边框 | 难扫读一条规则的范围/类型/金额/依据 | 同一规则用稳定网格，窄屏按原DOM顺序堆叠；确认始终可见 | before_v2/1440_classification.png、390_detail.png |

## 3. 唯一主方向

推荐“**清楚的商户工作台**”：借鉴 Shopify 公开商户应用布局的任务层级，保留数证智析名称与既有青绿识别。浅中性背景、白色内容面、细边框；只在主要操作、选中与链接使用青绿。Linear 仅补充对齐与降噪，Atlassian 仅补充文字层级，不拼接三家品牌。

保留现有导航、路由、步骤、业务操作名称、人工确认和结果口径。先只做三类现有页面样板；不新增工作流、经营指标、算法、智能体或大屏。

## 4. 11条落地规则

| 规则 | 具体应用 | 功能保护与验证 |
|---|---|---|
| R01 页面标题与主要操作同一水平基线 | 月报月份、历史选择与生成；列表标题/搜索；表单抽屉标题 | 不复制按钮、不改入口，窄屏换行仍有文字 |
| R02 同一区域仅一个视觉主操作 | 生成/确认用primary；列表查看/依据用secondary或文字按钮 | 不删除取消/历史/导出/帮助；逐入口核对 |
| R03 产品数据保持表格，工具栏按查询/筛选/状态分组 | 商品列表用同一边框容器，搜索筛选稳定对齐 | 原列/排序/页码/筛选与详情返回状态保留 |
| R04 表单按现有任务分组，不改步骤 | 字段/业务口径/确认；分类默认值和逐条规则 | 必填/禁用/确认逻辑完全保留，错误近控件呈现 |
| R05 4px节奏建立间距 | 8/12/16/24/32；内容分隔代替重复大卡片 | 只减少冗余空间，不把输入或按钮压小 |
| R06 三层文字加一层关键数字 | 页标题22、模块18、正文14–16、指标28；辅助14优先 | 不隐藏长名称/币种/完整精度，不用12px塞下所有内容 |
| R07 同类指标一致表面，风险色只表达真实状态 | 月报金额/销量/商品数；受限与风险文字提示 | 不补增长箭头；未知、零、失败分别表达 |
| R08 数字可纵向比较 | 金额/销量/占比右对齐、等宽数字、单位清楚 | 不改format、舍入、小数、币种、原始值 |
| R09 简单边框和表面建立分组 | 月报带状区域、列表容器、抽屉分节 | 保留有价值的卡片；只给浮层必要阴影 |
| R10 辅助入口克制而可发现 | 帮助保持短文字与既有图标；AI辅助面板不抢主体 | 42主题/真实模型状态/证据入口完整，键盘焦点与草稿不丢 |
| R11 视图与弹层一起验证 | 月报/列表/复杂表单正常、受限、错误；所有视口 | portal主题、Select、Drawer叠层、200%缩放；没有像素验收就不宣布完成 |

## 5. 样板基础规范（待真实页面校验）

| 项目 | 推荐起点 | 实现边界 |
|---|---|---|
| 颜色 | 品牌 #087F73；文字 #1F2933；辅助 #53616F；边框 #DDE2E5；浅背景 #F5F6F7；表面 #FFFFFF | 语义红/黄/绿沿用AntD并有文字，不自行制造风险信号；实际计算对比度 |
| 字体 | 现有系统字体 Segoe UI/PingFang SC/Microsoft YaHei/sans-serif | 不下载商业字体或外部CDN；font-variant-numeric: tabular-nums 用于数值 |
| 字号 | 页标题22/28行高，模块18/26，正文14/22，长帮助16/26，关键数字28/36 | 200%和390px实看；不通过缩字隐藏内容 |
| 间距 | 4px基数；组间24，组内12/16；桌面主体24，窄屏16 | 不新增空洞欢迎区；表单密度和结果密度分开验证 |
| 圆角/边框 | 控件6、容器8、1px中性边框 | 不用每个数字一张高阴影圆卡片 |
| 阴影 | 页面容器不加大阴影；弹层保留轻阴影 | 不影响遮罩、焦点、命中检测 |
| 图标 | 现有 @ant-design/icons，常规16/18；保持业务意义 | 主要操作保留文字；无机器人/魔法装饰新增 |
| 按钮 | 常用高度36–40；触屏关键目标至少40；明确焦点 | 采用公开token或局部class，不改htmlType、disabled、loading、handler |
| 表格 | 表头浅灰、正文白、细行线、数值右齐、局部横滚 | 不移除列，不改排序/聚合/分页，长名称可完整查看 |
| 表单 | 标签稳定，说明紧邻，规则在原DOM顺序网格排布 | 不改字段key、value/onChange、确认条件、preview_token或校验 |
| 弹层 | 同一字体/边框/间距；抽屉最大100vw、内部可滚 | 保留商品1000/助手1100/依据1200/帮助1300；不改挂载/事件 |
| 图表 | 保留现有青绿折线、真实点和浅网格，仅容器统一 | 不换库，不动输入/坐标/缺失值/单位/日期 |

## 6. 明确拒绝采用的参考做法

- Shopify 的嵌入式后台壳、Polaris/Web Components及平台规范专属导航：本站为独立 AntD 应用，不增加第二组件库或移植账户结构。
- Linear 的快捷键密集操作、暗色项目管理结构、极小标签及复杂主题生成器：小商户主要任务与该产品不同，不扩大信息架构范围。
- Atlassian 的品牌字体、标识和整套页面：只采用字号角色和阅读原则；中文系统字体更符合本轮依赖和许可边界。
- 展示大屏、渐变/玻璃背景、营销欢迎标题、装饰AI图片、全表转卡片：妨碍长期核对经营数据，不新增。

## 7. 方向确认检查点

在本轮真实基线补齐并独立提交后：①月报，②商品列表及详情抽屉，③字段映射或复杂分类表单。采用相同输入、同一冻结报告与视口的前后截图，正常和至少受限/错误状态；构建/合同/确定性结果/真实浏览器回归及portal检查。

提供实际独立预览后，**暂停全站扩展，等待用户确认方向**。本轮基线18100、样板18101已运行；本机隧道18110/18111已回读核对，见BEFORE_AFTER。不得合并main、替换旧演示、修改正式项目或业务数据库；版本仍0.6.3，候选差异由Git SHA标识，不提前发布新稳定tag。

## 已确认方向（2026-10-19）
