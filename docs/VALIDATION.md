## 复现入口

按 [部署指南](DEPLOYMENT.md) 安装依赖，在隔离环境中运行。先审查测试脚本的数据路径；部分业务验收脚本包含既有环境假设，不能直接对正式实例执行。

```bash
(cd frontend && npm run build)
node scripts/test_calendar_dates.mjs
node scripts/test_report_selection.cjs "$PWD/frontend/src/reportSelection.ts"
node scripts/test_sales_signals.cjs "$PWD/frontend/src/salesSignals.ts"
```

后端测试位于 `scripts/test_*.py`。在配置好临时目录的独立 Linux 环境，可按以下入口发现并执行；当前旧 API 准备阶段会出现上述错误。维护者应补齐合法认证准备后重新验证，不能将“测试可以启动”作为通过。

```bash
PYTHONPATH=backend .venv/bin/python -B -m unittest discover -s scripts -p 'test_*.py' -v
```

浏览器复核至少覆盖：新账号 → 新店铺 → CSV/XLSX 预览 → 字段/分类/范围 → 月报 → 历史切换刷新 → 商品原始记录 → 备注 → 客户与共购 → 真实模型与回退 → HTML/CSV/JSON 与打印 PDF。日期选择还应覆盖月初、月末、闰日、手动输入和不同视口。

## 已知限制

1. 旧 API 测试认证准备尚未全部适配；完整原样回归未全通过。
2. 当前包标记仍为 0.5.0，与独立算法版本不同；交付以 Git SHA 为准。
3. 部分运维/验收脚本含既有部署路径，新机器需显式配置；原生 Windows 后端不是已验证部署平台。
4. 无真实异常标签，不能给出异常检测准确率或确定原因。
5. 无成本、库存或可靠客户信息时，不推断利润、采购量或客户价值。
6. 模拟/公开数据验收不是独立真人试用或真实商户收益验证。
7. 外网 HTTPS、运行监控、备份保留策略和账号恢复流程需部署者配置；没有公开演示服务可用性承诺。
8. 团队自研代码许可证尚未确定，详见 [THIRD_PARTY.md](THIRD_PARTY.md)。
