- 初始权限测试使用旧式路由遍历，遇到当前FastAPI惰性路由结构而报错；改为完整解析后的OpenAPI列表，保持逐接口拒绝断言。

- 第二次发现快速切换到注册页时重置effect可能清空刚填写字段；改为独立有key的登录/注册页面，去掉延迟重置，重跑通过。
- `scripts/ui_redesign/test_presentation_contract.cjs` 等旧任务快照守卫要求后端、路由和依赖文件相对2026-10-14基线完全不变，不适用于新增账号的任务；原测试未删除或降低断言。其失败输出单独保留，并和当前基线对照：基线的12项全部通过。新增账号有意修改认证、路由及账号菜单，因此历史“只改UI、后端与壳层完全不变”断言不适用本轮；不能写成全部前端测试通过。帮助内容、报告解释等适用测试另行执行。

## 操作与限制

新用户使用自己设置的用户名/密码，没有默认管理员密码。历史项目不自动归属于首个用户。经过维护者核实后可使用 `account_admin.py` 明确分配单个未归属项目或重置密码，实际工具测试只使用临时数据库。

没有邮箱自助找回、邮箱验证、账号删除或多角色协作权限。当前为个人账号独立空间；服务器管理员仍控制系统和数据库，账号隔离不等于对服务器管理员的加密隔离。原系统单worker限制保留，多账号不会获得独立计算资源。

浏览器产物、Cookie、密码和完整商户数据不得进入Git；脚本为测试随机生成密码，只在进程内使用，认证请求不进入业务请求日志。全部主动工作产物位于D/E盘任务目录或远端隔离目录，未申请C盘例外；不能保证操作系统或Codex后台绝对零写入。
