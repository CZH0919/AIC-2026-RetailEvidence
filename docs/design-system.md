# 界面设计规范

## 视觉语言

以项目和用户任务为中心，保持轻量、克制、清晰的专业分析工具质感。桌面采用 216px 白色侧栏、冷灰工作背景与单一白色列表区域；避免堆砌统计卡片和虚假图表。

| 项目 | 规范 |
| --- | --- |
| 背景 / 内容 | `#f6f8fa` / `#ffffff` |
| 主文字 / 次文字 | `#182b37` / `#65788a` |
| 强调色 / 分隔线 | `#087f73` / `#e0e7ec` |
| 字体 | Segoe UI、PingFang SC、Microsoft YaHei、sans-serif |
| 层级 | 页标题 34px，区块标题 18–22px，正文 14–15px，辅助信息 12px |
| 几何 | 内容区圆角 8px、对话框 12px、低对比边界、有限阴影 |
| 间距 | 8px 基础节奏；主要区域 24–38px；表单标签与输入保持一致间距 |
| 图标 | Ant Design outline 图标；功能图标约 18–24px，空状态使用同一图标语言 |

项目标记为青绿、海蓝、琥珀、烟紫，用于辨识，不代表质量等级。

## 组件和状态

- Shell：品牌、主导航、最近访问、面包屑、指南及移动端抽屉。
- ProjectLibrary：头部主操作、搜索、真实项目列表、空列表与搜索无匹配状态。
- ProjectSpace：项目标题、说明、编辑、概览/数据页、真实创建和更新日期。
- ProjectEditor：复用创建/编辑表单，明确必填、长度提示、保存中、字段错误与并发冲突。
- States：加载骨架、空状态、错误恢复，不能把读取失败展示成空项目成功。
- Guide：面向使用者的数据准备说明，不显示运行地址、开发阶段或实现备注。

小于 760px 时侧栏改为可关闭导航抽屉，搜索独占一行，列表保留名称与说明，项目详情改为单列。长项目名换行，列表长文本省略；全名可在详情查看。按钮/链接有键盘焦点样式，表单带标签，状态提供可读提示，减少动态效果偏好得到尊重。

## 文案与验证

所有可见文字只表达用户任务、数据含义和真实状态。没有数据时说明下一步；没有上传实现时提供文件准备指南，不展示假的上传成功。后续分析页面不能用示例指标冒充用户结果。

核查项目创建、返回列表、进入详情、编辑、切换、刷新、长文本、空搜索和失败恢复；桌面及窄屏均以实际浏览器验证。构建成功不代替视觉与交互验收。
