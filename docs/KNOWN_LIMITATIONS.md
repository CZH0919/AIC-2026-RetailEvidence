# 已知事实限制

- 公开 Online Retail 是英国在线批发零售历史数据，不是真实小店试用。分类和费用排除是明示验收假定，不替商户确认会计口径。
- 复杂销量模型没有超过四周均值。相同冻结时间切分下简单法test MAE63.629083/WAPE65.399894%，复杂法90.576004/93.096754%；1000商品资源上限，382发布，不承诺整月精确备货。
- 异常无真实标签，93341测试日样本中2106报警，简单规则10473；无识别准确率，备注来源仍是用户人工核对。
- 缺库存/在途/成本时不补造采购量或利润；退款另列，正向销售额不是净利润。整单金额不能可靠分项时金额口径保持未知。
- 月汇总不能生成日曲线、逐日异常或七天预测；单月历史也可能不足，正确降级是预期行为。
- 单Worker、CPU两线程子进程、8GiB地址空间与RSS预算、600/1200秒预算、磁盘20GiB门槛保持。模型4CPU线程、1并发、2048上下文。前端967KB chunk存在体积提示；未调整阈值掩盖。
- 本地/回环可信环境，没有账号鉴权。SSH隧道不是评委公网入口；HTTPS、鉴权与公网部署尚未授权或执行。
- 未执行真实非开发者独立试用、真实商户反馈、录制视频或比赛平台提交；需真实人员完成，模型不能冒充。
- 旧S07字段AI确认、自然语言任务操作及其他S08–S09设想单列待团队裁决；现有确定性列名建议与销售证据问答不能称作完整字段AI映射。
- 团队自研源码没有确认的公开开源许可；授权范围为个人私有托管。Groceries底层数据再分发权利需另核实，不将其原资产加入仓库。
- 本轮禁止主动C盘写入，使用D盘与远端个人目录；Windows/Codex/操作系统后台行为无法作绝对零写入保证，没有获批C盘例外。
