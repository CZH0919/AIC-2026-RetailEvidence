# 数证智析网站使用说明（0.6.3）

系统帮助你复盘销售和核对商品；销售额不是利润，预测也不是保证采购量。页面上的“怎么填写？”“如何理解？”可点击查看例子；未知数据保留未知，不要猜。Esc关闭帮助，原表单仍在。

## 从一份表开始

1. 项目库新建店铺项目，名字如“小林便利店”，说明可留空。同店新月份继续原项目，不同店/不同单位分开。
2. 进入数据记录，上传CSV或XLSX。第一行列名，一列一种含义，不放合并表头或合计。上传成功后仍需预览与确认。
3. CSV先用UTF-8；乱码尝试GB18030/GBK，只有一列核对分隔符。Excel只选择结构一致的销售工作表；说明页不能合并到销售数据。
4. 看一行代表什么：一件商品的一笔交易、一天汇总或一个月汇总。月汇总填写它所属月份；月汇总无法恢复每日走势或七天预测。
5. 核对字段，未知列留空。建议是待核对的候选，不是AI已经确认。商品编号稳定区分商品，名称便于看；客户和订单编号不要用手机号。缺客户限制分群，缺订单限制共购/客单价，缺日期限制逐日分析。
6. 选择金额来源：单价是一件价，行金额是该行商品金额，订单总额是整张小票。两瓶水每瓶5，行金额10；同单面包3，总额13，只能计一次。缺金额不补零，不用整单金额任意分配商品。币种不会自动换汇；单位、格式、时区按原表确认。
7. 确认取消和退货实际含义，不能将未知状态当正向销售。保存设置形成新字段版本，旧报告不会自动改变。

## 分类、检查与月报

选择生成月报、数据和月份。按卡片文件名/V/M检查分类：实物、运费/服务、人工调整、其他、待确认。实物进入销量/排行/预测/备货；金额是否计入另行确认。规则精确匹配编号、已映射分类或来源行，写明依据；未知保留待确认，不按名字含POST一刀切。

同月追加选择全部相关文件；重叠时核对来源和替换范围。完全重复只是候选，真实重复购买不能误删。只有知道全月记录与停业日完整时才确认覆盖，缺少的日子不能自动视为0。检查通过并人工确认后生成月报。

月报看当前月份、币种、单位、分类分项和统计范围。上月缺失/不可比就没有可靠月度比较。点全部商品看完整表，首页摘要不代表全部商品。异常是偏离历史参考的提醒，不能证明原因或经营事故；点异常日期查看原始记录，再保存核查备注。备注不改销售数字。遇到他人已更新的提示，读取最新、核对草稿后手动保存。

## 预测和备货

仅达到发布条件的商品显示未来七天参考；月汇总、历史不足等说明不能预测。历史误差是过去测试中参考与实际的偏差，不保证未来。库存必须对应本次预测起点：历史2011年报告不能填今天库存。可售库存排除损坏/已预留，确定到货只填已确认在期间到达的数量，不确定到货不扣除。备用量由店主决定，包装单位与销量单位一致；结果是按包装向上取整的七天缺口参考，还要考虑交货时间、保质期与资金，不能保证不缺货。

## 助手、更多分析与导出

销售助手选例题可填问题，编辑后点提问；AI只解释当前证据，不能知道未上传库存、利润或原因。程序计算数字；AI辅助解释、计算依据说明、使用说明、需要澄清、数据限制和预设说明分别显示。模型不可用时仍能看确定性月报。

从顶部“更多分析”进入数据质量、客户分群和商品共购，与“销售月报、商品明细、数据记录”并列。进入后先确认范围和做质量检查。客户分群和共购各用“历史结果”下拉框切换以前的分析，按时间和状态辨认；这些是运行记录，不是客户类别。RF看最近购买与购买频次，RFM再看金额；订单或客户/金额不足先补数据或选择安全子集。群体是描述，不代表客户标签真相。共购需要订单篮子：支持度是出现频率、置信度是买前项后也买后项的比例、提升度是相对总体常见程度；不是因果，也不保证交叉促销收益。发布门槛不足时按页面原因补数据，不强行当经营建议。

历史下拉保存当前报告到地址，可刷新或复制；核对V数据版本、M字段版本与运行。导出HTML月报、完整商品CSV、分类与业务记录CSV、JSON；浏览器打开HTML后打印为PDF。首页五件摘要不截断完整导出。只分享有权处理的数据。任务排队可等候或取消；失败先看原因、修正配置/数据后重新运行，旧结果不自动被覆盖。

本文对应本轮真实浏览器验证路径；尚无真实商户研究，不代表所有人无需指导就能熟练操作。详细自查与未验证分支见UX_GUIDANCE_ACCEPTANCE。

## 核对分析质量与解释

分群结果中的最近购买天数、购买次数和购买金额是各组的中位数；需要进一步核对时打开“分组质量详情”。共购的“共购质量详情”保留前五候选命中率、可给建议比例及热门方法对照，测试命中不等于实际购买率。HTML分类附页的“报告复核信息”可展开查看同一配置的校验标识。

销售助手可以回答“请介绍本月销售情况”，在商品页可问“预测数字、计算方法和库存限制是什么”。程序依据说明直接使用本报告的数值，不表示模型实际推理；等待超时或解释未通过核对时先看月报计算结果，不把失败当成功。

## 2026-10-19 界面位置更新

操作顺序和分析口径保持。项目库以列表显示店铺，首次步骤可点击“首次使用：三步开始分析”。导入时原始数据仍直接预览；已经保存的数据记录页点击“查看原始数据预览”展开，不影响数据版本。

字段页面“AI 辅助理解字段”按需展开，问题和字段草稿不会因关闭说明丢失；建议仍需人工确认。质量页点击“本次范围与策略”查看范围，点击“查看处理过程”查看事件；当前状态、实际失败和操作按钮仍直接显示。月报金额分类、关注原因与行动依据可展开，常用口径在“数字怎么算？”中查看。商品详情和计算依据沿用逐层返回和Esc关闭。

页面简洁不代表数据被删除。完整商品、异常来源、备注、全部导出及已有帮助保持原有流程；“更多分析”改为顶部并列入口；历史报告继续对应原run。
