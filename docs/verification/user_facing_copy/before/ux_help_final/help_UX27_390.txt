这是什么

销售额按确认金额口径统计正向记录，不是利润，也不自动净扣所有退货；销量只来自已确认实物。

如何选择

先核对月份、币种、单位和分类金额分项。订单总额只每单一次，商品金额不会凭空分摊。

例如

销售1000元不能说明赚1000元；还缺进货成本、费用等。

没有数据时

没金额显示销量；没可靠订单显示有销售记录商品数，不编造客单价。

请留意

误认为利润或混淆金额与数量范围会作出错误经营判断。
