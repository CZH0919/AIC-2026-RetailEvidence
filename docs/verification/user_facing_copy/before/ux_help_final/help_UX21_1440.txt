这是什么

完整表示这段期间有销售就一定被记录。确认后无记录的商品日才可按零销量处理。

如何选择

只填确定完整的起止；停业日仅填真实已知日期，多天逗号分隔，不用它猜缺货。

例如

整月收银记录齐全可确认；漏导一周不能勾选完整。

没有数据时

记录不齐保留未确认，继续做可用复盘，但比较、异常或预测可能不足。

请留意

把漏数据当零销量会产生假下降、异常和错误预测。
