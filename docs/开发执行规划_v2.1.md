## 本轮固定取舍

- 店铺内主要导航是月报、商品明细、数据记录；分群与共购在更多分析。
- 月报只讲本月概况、默认五件重点商品、最多三件下月先做的事。
- 所有达到条件的商品仍可查、可筛选、可导出，不把摘要数量当分析上限。
- 一个月也能有月报，不要求客户号或订单号；完整日历史不足时不做模型预测。
- 预测仅为接下来七天累计量；库存未知时不算补货数量，不把点估计乘四。
- 所有验收销售数据来自真实公开数据；派生月汇总注明原文件和汇总口径。
- 原代码结构不迁移。新增模块的职责、数据合同、迁移和 API 见项目 `docs/代码结构与接手说明.md`。

## 验收不能混淆

“程序跑通”“公开数据算数正确”“模型相对基线有提升”“商户确实受益”是四件不同的事。上线演示只证明前两项的一部分。Online Retail 使用简单预测参考，独立周数据的小幅提升不冒充小商户效果；异常提醒没有真实原因标签，不能宣传准确率。

商户实测、由商户确认的异常标签、真实进销存收益和参赛材料人工审核属于后续真实业务验收，不由本轮公开数据截图自动证明。
